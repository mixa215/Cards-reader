# Cards-reader

Мультиплатформенный парсер цен с маркетплейсов и досок объявлений (**Ozon**, **Wildberries**, **Яндекс Маркет**, **Avito**) на Python.

## Особенности

- **Маршрутизация ссылок**: автоматическое определение платформы по URL (`src/router.py`).
- **Поддержка Avito**: трёхуровневая каскадная стратегия извлечения данных лота (JSON-LD Schema.org -> SSR Hydration Data -> DOM/CSS/Meta-теги) с детекцией статусов закрытия и блокировок (`src/avito_worker.py`).
- **Антидетект-браузер**: использование stealth-движка **Camoufox** для Ozon, Wildberries и Avito (десктопный режим), обход проверок браузера и защита от блокировок.
- **Persistent Profile**: для Яндекс Маркета используется сохранение сессии и автоклик капчи.
- **Точечный кроп**: захват исключительно селектора блока цены (с проверкой наличия знака `₽` / `руб`).
- **Распознавание цены**: OCR через библиотеку **EasyOCR** с предобработкой изображений и нормализацией чисел.
- **Экспорт в Excel**: автоматическое сохранение структурированного отчета (`.xlsx`) с гиперссылками на карточки и скриншоты цен.

## Структура проекта

```text
Cards-reader/
├── openspec/
│   └── specs/
│       └── market_price_scanner.md  # Техническое задание проекта
├── output/                          # Сгенерированные отчеты Excel
├── screenshots/
│   ├── prices/                      # Кропы блоков цен
│   └── errors/                      # Скриншоты экранов блокировок / ошибок
├── src/
│   ├── config.py                    # Настройки путей, таймаутов, селекторов
│   ├── main.py                      # Точка входа и диспетчер пайплайна
│   ├── router.py                    # Валидация и маршрутизация ссылок
│   ├── browser_worker.py            # Браузерные адаптеры маркетплейсов
│   ├── ocr_worker.py                # Распознавание цен через EasyOCR
│   └── excel_worker.py              # Запись и форматирование Excel таблицы
├── requirements.txt                 # Зависимости Python
└── urls.txt                         # Входной список ссылок
```

## Установка и запуск

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/mixa215/Cards-reader.git
   cd Cards-reader
   ```

2. Создайте и активируйте виртуальное окружение:
   ```bash
   python -m venv .venv
   # Windows:
   .venv\Scripts\activate
   # Linux / macOS:
   source .venv/bin/activate
   ```

3. Установите зависимости и бинарники браузера:
   ```bash
   pip install -r requirements.txt
   camoufox fetch
   ```

4. Добавьте ссылки на товары в файл `urls.txt` и запустите парсер:
   ```bash
   python src/main.py
   ```
